# Security policy

The plugins here hold no code that touches your data: each one starts the MCP
server of an app installed on your own computer, and teaches the assistant how
to use it. A plugin's launcher only looks for that app and runs it; it opens no
network connection and keeps nothing.

## Reporting a vulnerability

**Do not open a public issue.** Use either private channel:

- **Email** <rgdevment@tisty.app>, subject `[SECURITY] short description`.
- **GitHub Security Advisory**: the *Security* tab, *Report a vulnerability*.

A problem in an app itself, such as Tisty, follows that app's own policy:
[Tisty's](https://github.com/rgdevment/Tisty/blob/main/SECURITY.md).

You will get an acknowledgement within 48 hours, and credit in the release
notes unless you prefer otherwise.
