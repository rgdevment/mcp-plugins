Tisty is not installed on this computer, or not where this launcher looks, so its tools are not available.
Install it from https://www.tisty.app/docs/installation/: on Windows from the Microsoft Store, with `winget install rgdevment.Tisty` or the installer, on macOS with `brew tap rgdevment/tap && brew trust rgdevment/tap && brew install --cask tisty`.
Open it once, then restart this assistant. If Tisty turns it away, its door is closed: open it again in Settings › Assistants.
If Tisty is installed somewhere else, set TISTY_PATH to the full path of its `tisty` command.
